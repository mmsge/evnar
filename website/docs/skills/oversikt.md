# Skills i evnar

`evnar` inneheld **11 skills**. Kvar av dei bur i `.apm/skills/<namn>/` og kan
installerast via [APM-ruta](../installering/apm.md) eller hentast enkeltvis med
[last-ned-og-last-inn-ruta](../installering/manuell.md).

| Skill | Kva han gjer |
|---|---|
| [`books`](./books.md) | Søk i lesehistorikk frå StoryGraph og Bookwyrm |
| [`doctor-who`](./doctor-who.md) | Slå opp, svar på og diskuter alt om Doctor Who |
| [`favicon`](./favicon.md) | Set opp eller fiks favicon-ar for kva som helst nettprosjekt |
| [`git`](./git.md) | Ekspert på git-arbeidsflyt: commits, branchar, PR-ar, CI |
| [`lastfm-scrobble-report`](./lastfm-scrobble-report.md) | Lag PDF- og CSV-rapport over Last.fm-scrobbles for ein artist |
| [`mastodon`](./mastodon.md) | Hent og vis siste innlegg frå @markus@skvip.lol |
| [`new-project-scaffold`](./new-project-scaffold.md) | Set opp nye prosjekt med komplett, produksjonsklar struktur |
| [`obsidian-template`](./obsidian-template.md) | Lag nye Obsidian-templatar tilpassa vaulten til Markus |
| [`project-review`](./project-review.md) | Gjennomgang av eit kodeprosjekt med rangerte forbetringsforslag |
| [`repo-settings`](./repo-settings.md) | Set standard GitHub-innstillingar på eit repo |
| [`session-start-hook`](./session-start-hook.md) | Lag SessionStart-hooks for Claude Code på nettet |

:::tip
Lurer du på korleis ein skill blir aktivert? Agenten les `description`-feltet i
`SKILL.md` og slår på skillen når oppgåva di matchar triggerane som er lista der.
:::
