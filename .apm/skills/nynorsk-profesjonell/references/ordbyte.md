# Bokmål → nynorsk: bytetabell for fagtekst

Fasit for omsetjing av profesjonell tekst. Alle para under er henta frå ekte
kompetanse-/prosjektskildringar Markus har fått omsett. Bruk tabellane som
oppslag; les `SKILL.md` for reglane og registeret.

To prinsipp:
1. Vel den puristiske/heimlege forma der det ikkje går ut over presisjonen.
2. Lat fagtermar og eigennamn stå (eigen seksjon nedst), og skriv standard
   nynorsk for dei munnlege kvirkene hans (samen→saman osv.).

---

## 3. Verb på -ere — held på -ere (IKKJE a-infinitiv)

Desse skal **ikkje** a-infinitivast. Infinitiv `-ere`, presens `-er`,
preteritum `-erte`, partisipp `-ert`/`-erte`:

> definere, modellere, spesifisere, identifisere, vurdere, strukturere,
> etablere, adressere, implementere, prosessere, distribuere, fungere,
> redusere, publisere, koordinere, initiere, raffinere, containerisere

Døme: «for å **definere** og følgja opp standardar», «for å **vurdere**
kvaliteten», «skulle **adressere** problemstillingane», «for å **etablere**
eit godt grunnlag».

## 10. Termar som blir ståande (ikkje fornorsk)

Eigennamn og innarbeidde fagtermar:

> Terraform · Azure · Azure Functions · WebJobs · Web Apps · Service Bus ·
> GitHub · GitHub Actions · CI/CD · Python · .NET · FastMCP · MCP · Docker ·
> RDF · OWL · SPARQL · REST-API · Datalog · triplestores

Innarbeidd sjargong som ikkje skal omsetjast:

> pull requests · workflows · backlog · deploye · standup · planning · review ·
> retrospektiv · team leads · repo · smidig · Infrastructure-as-Code ·
> Disaster Recovery

Behald òg `gjenbruk`/`gjenoppbygging`/`gjenoppretting` (ikkje *att-*) og
`database`/`infrastruktur` — klarleik framfor ekstrem purisme.

## 11. Munnlege kvirker — bruk standard nynorsk i fagtekst

Desse formene brukar Markus i uformell stil, men IKKJE i profesjonell tekst:

| Hans uformelle form | I fagtekst |
|---|---|
| samen / til samen | saman / til saman |
| samenliknar | samanliknar |
| alikevel | likevel |
| (sporadiske typo) | rett opp |

Konservative former han derimot HELD på, også i fagtekst: `fyrst`/`fyrste`,
`hovud-`, `gong`/`gongar`, `sumar`, `ven`/`venleg`, `tri`.
