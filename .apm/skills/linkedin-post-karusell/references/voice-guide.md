# Markus sin LinkedIn-stemme

Korte prinsipp og eksempel henta frå dei siste postane hans. Bruk dette som klangbotn når du skriv.

## Tonen

Markus skriv på **nynorsk**. Tonen er reflekterande, profesjonell, og varm — utan å vera marknadsførsk. Han skriv som ein utviklar/konsulent som likar å tenkja høgt, ikkje som ein influencer. Innlegga skal kunna lesast som ein liten dagboknotat.

Vanlege drag:

- **Eittsetnings-hook**. Aldri ein lang ingress. Første line skal skapa nysgjerrigheit eller setja opp ein motsetnad.
- **Korte avsnitt**. Eitt avsnitt = éi tanke. Sjeldan meir enn 2–3 setningar.
- **Personleg vinkel**. "Eg lurte på...", "Eg laga...", "Eg synest...". Ikkje "vi" eller "ein".
- **Reflekterande sluttsetning**. Ofte ein observasjon eller ein liten visjon, ikkje ein hard CTA.
- **Hashtags i botnen**. 3–5 stk, relevante.

## Hook-eksempel

Sjå korleis dei opnar med ein påstand eller ein motsetnad:

- "Ein LLM veit ikkje svaret, han veit berre kva eit svar kan sjå ut som."
- "KI skapar ikkje verdi av seg sjølv."
- "Du kan nytte generativ KI til meir enn berre ein chatbot."
- "Eg tykkja det var vanskeleg å sjølv finne ut om eg har fått betre råd dei siste åra."
- "Tabellane fortel kven som vann. Dei seier mindre om kvar stemmene kom frå."

Mønsteret: éi setning som anten utfordrar eit vanleg syn, eller skildrar ein observasjon som lesaren kjenner seg igjen i. Aldri "I dag vil eg dele...".

## Historie-bogen

Postane følgjer som regel denne strukturen:

1. **Hook** — ein observasjon som setjer opp spenning.
2. **Personleg motivasjon** — "Eg ville berre vite om...", "Det fekk meg til å lure...".
3. **Kva eg gjorde** — kort om bygginga, gjerne med "Frå idé til publisert nettstad same dag" eller liknande.
4. **Kva eg fann / refleksjon** — kva som overraska, kva som er interessant.
5. **CTA / lenke** — "Prøv han på: ...", "Sjå koden her: ...".

## Standardlinjer som ofte gjentek seg

- **"Bygd raskt med språkmodellar, men sjølve appen brukar ikkje KI."** Bruk når relevant — signaliserer både kapabilitet og fagleg integritet.
- **"Frå idé til publisert nettstad same dag."** Brukbar når byggjetida var kort.
- **"Open kjelde. Opne data."** For prosjekt med GitHub-lenke.

## Hashtag-mønster

3–5 hashtags, blanding av brede og smale:

- Brede: `#KunstigIntelligens`, `#KI`, `#GenerativKI`, `#OpenSource`
- Smale: `#Sankey`, `#SSB`, `#Stortingsval`, `#Datavisualisering`
- Hendingsbaserte når det passar: `#Bouvet`, `#BergenNæringsråd`

Ikkje skriv `#AI` (han brukar `#KI`).

## Karusell-stil

Karusellane hans har (Bolk-stilen):

- **Djup skog-grøn bakgrunn** (#143521) med **lime-grøn aksent** (#9fe822)
- Store, feite **kvite** overskrifter (Lato Black) som fyller plassen
- Lyst grønt kicker øvst i kvar slide (UPPERCASE med ekstra spacing) + ein kort lime-strek under
- Progress-bar med lime utfylte segment øvst
- "Prosjektnamn · personleg notat" + "01 / 06" i botnen
- **Bilete og line-ikon framfor tom plass** — gjerne eit stort halvsides avrunda foto på opningsslida
- Lyse **krem-kort** (#f1ede2) ber sjekklister og diagram
- Kort-baserte oppsett for tal og step-by-step (grøne kort, lime tal og piler)
- Sluttslide: mørkt URL-panel med lime label + CTA-pil

Designhaldninga: **store typar, lite luft, mykje visuelt.** Karusellane er **portrett 4:5** og skal lesast saman med post-teksten — ikkje gjenta han, men utvida han med bilete og funn.

## Eksempel — heile post

```
Tabellane fortel kven som vann. Dei seier mindre om kvar stemmene kom frå.

Nokon delte eit stilig diagram av kor veljarane flytta seg mellom dei to førre stortingsvala. Det fekk meg til å lure: fanst det fleire val med same data?

Det gjorde det. Med ein enkel prompt til ein språkmodell fekk eg sløyfa tre stortingsval saman i ein figur.

Mest overraskande funn: Frp dobla seg, men berre 28 % av 2025-veljarane deira var Frp-veljarar i 2021. Kvar tredje stemte ikkje sist. Kvar femte var Høgre-veljar.

Open kjelde, opne data: mmsge.github.io/stemmeflyttare

#Stortingsval #Datavisualisering #SSB #Sankey #OpenSource
```

Legg merke til: hook er éi setning. Avsnitta er korte. Det ligg eitt konkret tal (28 %) som hookar mot karusellen. CTA er kort og naken — ingen "klikk her for å sjå meir!".
