# Generic Project Reference

Use this when the language/stack isn't covered by a dedicated reference file.
Adapt every section to the specific language. The principles apply universally.

---

## Universal principles

### Linting & formatting
Every language has a de-facto standard. Use it:

| Language | Linter | Formatter |
|---|---|---|
| Rust | Clippy | rustfmt |
| Java | Checkstyle / SpotBugs | google-java-format |
| Ruby | RuboCop | RuboCop |
| C/C++ | clang-tidy | clang-format |
| Shell | shellcheck | shfmt |
| PHP | PHPStan | PHP-CS-Fixer |

### Test runners by language

| Language | Runner |
|---|---|
| Rust | `cargo test` |
| Java | JUnit 5 + Maven/Gradle |
| Ruby | RSpec |
| C | CMocka / Unity |
| PHP | PHPUnit |

### Coverage targets
- **≥ 80%** line coverage is the minimum acceptable target for any project
- Document the target in `README.md` and enforce it in CI (fail the build if coverage drops below threshold)

## Generic GitHub Actions CI template

Adapt `<setup-step>`, `<lint-cmd>`, `<format-check-cmd>`, `<test-cmd>`:

```yaml
name: CI

on:
  push:
    branches: [main]
  pull_request:

jobs:
  ci:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4

      # Language-specific setup
      - name: Set up environment
        # e.g. uses: actions/setup-java@v4 / dtolnay/rust-toolchain@stable
        run: echo "replace with real setup"

      - name: Install dependencies
        run: echo "replace with install command"

      - name: Lint
        run: <lint-cmd>

      - name: Format check
        run: <format-check-cmd>

      - name: Test with coverage
        run: <test-cmd>

      - name: Upload coverage
        uses: codecov/codecov-action@v4
```

## Docusaurus config (applies to ALL stacks)

```js
// docs/docusaurus.config.js
/** @type {import('@docusaurus/types').Config} */
const config = {
  title: '<Project Name>',
  tagline: '<One-line description>',
  url: 'https://example.com',
  baseUrl: '/',
  favicon: 'img/favicon.ico',
  organizationName: '<org>',
  projectName: '<repo>',

  presets: [
    [
      'classic',
      {
        docs: {
          sidebarPath: require.resolve('./sidebars.js'),
          editUrl: 'https://github.com/<org>/<repo>/edit/main/docs/',
        },
        theme: {
          customCss: require.resolve('./src/css/custom.css'),
        },
      },
    ],
  ],

  themeConfig: {
    navbar: {
      title: '<Project Name>',
      items: [
        { type: 'docSidebar', sidebarId: 'docs', label: 'Docs' },
        { href: 'https://github.com/<org>/<repo>', label: 'GitHub', position: 'right' },
      ],
    },
    footer: {
      style: 'dark',
      copyright: `Copyright © ${new Date().getFullYear()} <Project Name>. MIT Licence.`,
    },
  },
};

module.exports = config;
```

